# Uputstvo za rad tastaturom

Deklarant Pro podržava rad tastaturom na svim glavnim karticama. Prečice
ubrzavaju unos i pregled podataka, ali ne mijenjaju sadržaj deklaracije bez
uobičajene potvrde korisnika.

## Brzi pregled

| Prečica | Funkcija |
|---|---|
| `Tab` | Prelazak na sljedeće polje |
| `Shift+Tab` | Povratak na prethodno polje |
| `Ctrl+Tab` | Otvaranje sljedeće glavne kartice |
| `Ctrl+Shift+Tab` | Povratak na prethodnu glavnu karticu |
| `Ctrl+1` | Otvaranje kartice Faktura |
| `Ctrl+2` | Otvaranje kartice Naimenovanja |
| `Ctrl+3` | Otvaranje kartice Zaglavlje |
| `Ctrl+4` | Otvaranje kartice Šifrarnici |
| `Ctrl+5` | Otvaranje kartice Admin |
| `Ctrl+6` | Otvaranje kartice Agent |
| `Esc` | Zatvaranje dijaloga ili prekid trenutnog uređivanja kada je dostupno |

## Kretanje kroz zapise

Na karticama koje prikazuju više zapisa mogu se koristiti dvije jednake grupe
prečica:

| Prečica | Funkcija |
|---|---|
| `Alt+←` ili `Alt+A` | Prethodni zapis |
| `Alt+→` ili `Alt+D` | Sljedeći zapis |

Kombinacije `Alt+A` i `Alt+D` predstavljaju opcionu gaming alternativu. Obična
slova `A` i `D` nisu prečice i mogu se normalno unositi u tekstualna polja.

## Kartica Faktura

| Prečica | Funkcija |
|---|---|
| `Ctrl+N` | Dodavanje nove stavke |
| `Alt+←` ili `Alt+A` | Označavanje prethodne stavke |
| `Alt+→` ili `Alt+D` | Označavanje sljedeće stavke |
| `Ctrl+Z` | Poništavanje posljednje izmjene |
| `Ctrl+Y` | Vraćanje poništene izmjene |
| `Ctrl+Shift+Z` | Alternativno vraćanje poništene izmjene |

Strelice bez tastera `Alt` zadržavaju standardnu funkciju kretanja kroz ćelije
tabele i tekst unutar ćelije.

## Kartica Naimenovanja

| Prečica | Funkcija |
|---|---|
| `Alt+←` ili `Alt+A` | Prethodno naimenovanje |
| `Alt+→` ili `Alt+D` | Sljedeće naimenovanje |
| `Ctrl+N` | Dodavanje novog naimenovanja |
| `Ctrl+D` | Brisanje trenutnog naimenovanja |
| `Ctrl+S` | Čuvanje trenutnih izmjena |
| `Enter` u tarifnom broju | Pokretanje provjere tarifnog broja |

`Tab` i `Shift+Tab` prolaze logičkim redoslijedom kroz rubrike 31–46.

Brisanje naimenovanja može prikazati poruku za potvrdu. Prečica ne zaobilazi
ovu sigurnosnu provjeru.

## Kartica Zaglavlje

| Prečica | Funkcija |
|---|---|
| `Ctrl+N` | Pokretanje nove deklaracije |
| `Ctrl+S` | Pokretanje završne provjere |
| `Delete` u tabeli dokumenata | Brisanje sadržaja označene reference |

`Tab` prati polja Zaglavlja redoslijedom u kojem se obrazac popunjava.
`Shift+Tab` se vraća na prethodno polje.

Taster `Delete` briše referencu samo kada je fokus u tabeli priloženih
dokumenata. Ne briše cijelu deklaraciju.

## Kartica Šifrarnici

| Prečica | Funkcija |
|---|---|
| `Ctrl+N` | Novi zapis |
| `Ctrl+E` | Uređivanje označenog zapisa |
| `Ctrl+S` | Čuvanje zapisa |
| `Delete` | Brisanje označenog zapisa |
| `Alt+←` ili `Alt+A` | Prethodni zapis |
| `Alt+→` ili `Alt+D` | Sljedeći zapis |

Operacije brisanja zadržavaju postojeće poruke za potvrdu.

## Kartica Agent

| Prečica | Funkcija |
|---|---|
| `Enter` | Slanje poruke agentu |
| `Shift+Enter` | Novi red unutar poruke |

Kartica Agent nema prečice za prethodni ili sljedeći zapis jer je organizovana
kao razgovor i lista aktivnosti.

## Kartica Admin

Kartica Admin koristi standardne `Tab`, `Shift+Tab` i strelice za kretanje kroz
kontrole, liste i podešavanja. Direktno se otvara kombinacijom `Ctrl+5`.

## Važne napomene

- Obični tasteri `W`, `A`, `S` i `D` uvijek ostaju dostupni za unos teksta.
- Obične strelice služe za kretanje kroz tekst, tabele, liste i padajuće menije.
- Gaming prečice rade samo zajedno sa tasterom `Alt`.
- Kada je otvoren modalni dijalog, prvo završite ili zatvorite dijalog.
- Dostupna prečica je prikazana i u tooltipu odgovarajućeg dugmeta.
- Ako određena kartica nema pojam prethodnog ili sljedećeg zapisa, kombinacije
  `Alt+A/D` na toj kartici nemaju akciju.

## Preporučeni način rada

1. Otvorite željenu karticu kombinacijom `Ctrl+1`–`Ctrl+6`.
2. Krećite se kroz polja pomoću `Tab` i `Shift+Tab`.
3. Na Fakturi, Naimenovanjima i u Šifrarnicima koristite `Alt+A/D` ili
   `Alt+←/→` za promjenu zapisa.
4. Koristite kartične prečice za dodavanje, čuvanje ili uređivanje.
5. Prije brisanja pročitajte poruku za potvrdu.
