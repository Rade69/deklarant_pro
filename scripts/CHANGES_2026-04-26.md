# Izmene — 26. april 2026

## 1. Istorijska predikcija tarife po dobavljaču

### Problem
Kad se uvezu fakture od poznatog dobavljača, agent je predlagao tarifne brojeve samo iz baze znanja i LLM-a. Baza znanja može imati netačne unose sa faktura, a LLM nagađa. XML fajlovi iz prethodnih deklaracija (koji su prošli carinsku provjeru) sadrže validne tarifne brojeve — ali se nisu koristili.

### Rešenje
Dodat istorijski sloj u sve tokove za predlaganje tarifnih brojeva. Redosled provere:

```
1) XML sa carine (exporter_xml_index) — najvalidniji
2) Baza znanja (product_tariff_mapping)
3) LLM (DeepSeek)
```

### Izmenjeni fajlovi

**`services/agent/chat/tariff_intent_service.py`** — agent chat "popuni tarifne"
- `_get_exporter_name()` — nova metoda, izvlači dobavljača iz drafta
- `_try_history_match()` — nova metoda, poziva HybridMatchingService
- `propose_all()` — dodat istorijski sloj u petlji
- `propose_by_keyword()` — isto
- `_show_proposals()` — razlikuje izvor "istorija", "baza", "AI"

**`services/tariff/tariff_mapping_service.py`** — Faktura tab "Auto-popuni"
- `auto_populate_tariffs()` — dodat istorijski sloj pre baze znanja

### Korišćen postojeći servis
`HybridMatchingService` — nije menjan. Već je imao `_get_historical_candidates()` metodu.

## 2. Popravka zaglavljenog dugmeta "Pokreni analizu"

### Problem
Dugme je povremeno ostajalo sivo sa tekstom "⏳ Procesiram..." nakon brisanja i ponovnog dodavanja fajlova.

### Uzrok (dva sloja)

**Sloj 1** — `agent_controller.py`: `set_loading(False)` nije pozivan u svim granama (greška, clear, exception).

**Sloj 2** — `document_panel.py`: `setEnabled()` pozivan direktno bez resetovanja stylesheet-a. Ako je dugme bilo u loading stanju, stylesheet je ostajao siv i tekst "⏳ Procesiram..." iako je dugme enable-ovano.

### Rešenje

**`gui/tabs/agent/agent_controller.py`:**
- `_on_all_completed` — `set_loading(False)` pomeran na prvu liniju metode
- `_on_error` — dodat `set_loading(False)`
- `_on_clear_requested` — dodat `set_loading(False)`
- `_on_analyze_requested` — dodat try/except koji vraća dugme

**`gui/tabs/agent/widgets/document_panel.py`:**
- `_on_files_dropped` — `set_loading(False)` pre `setEnabled(True)`
- `_on_clear` — `set_loading(False)` pre `setEnabled(False)`
- `_on_file_removed` — `set_loading(False)` pre `setEnabled(False)`
